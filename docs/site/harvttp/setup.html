Build, USB-Images und Start

Diese Seite beschreibt den Projektpfad, in dem HarvTTP als ELF gebaut, auf das Programm-USB-Image gelegt und anschliessend vom HarvOS-Boot-ROM im Prozessor gestartet wird.

Typischer Build-Ablauf

powershell -ExecutionPolicy Bypass -File .\scripts\build_harvttp.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build_usb_images.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build_usb_elf_bootrom.ps1

Danach enthaelt das Programm-USB-Image das ELF und die Webroot-Dateien. Das Boot-ROM-Image enthaelt den Loader, der beim CPU-Reset ausgefuehrt wird.

PHP-8.5-Port vorbereiten

powershell -ExecutionPolicy Bypass -File .\scripts\build_php85_harvos.ps1 -Overlay

Dieser Schritt kopiert die HarvOS-SAPI nach C:\Users\dennis\Downloads\php-8.5.6-src\sapi\harvos. Das ist der echte Zend-Port-Andockpunkt. Ein Link in harvttp.elf ist erst nach HarvOS-libc, Heap und VFS-Streams sinnvoll.

Start der Testsuite

powershell -ExecutionPolicy Bypass -File .\scripts\start_harvttp_usb_boot_server.ps1

Der Startpfad bootet den HarvOS-Prozessor, laedt das ELF vom Programm-USB, bindet die Netzwerkschnittstelle an den Testpfad und wartet auf DHCP. Wenn Npcap/TAP korrekt eingerichtet ist, kann die vom Server bezogene IP im Browser aufgerufen werden.
